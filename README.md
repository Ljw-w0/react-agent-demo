# ReActAgent

## Introduction

A tool-enabled AI agent built with LangChain and LangGraph.

The agent follows the ReAct (Reasoning + Action) pattern to understand user requests, dynamically call external tools, retrieve or manage long-term user memories, and generate a final response.
